# 암기장

타이핑하며 외우는 앱입니다. 판례리스트를 세트 › 주제 › 암기로 정리해 두고, 원문을 보면서 오른쪽 입력창에 타이핑하면 스페이스를 누를 때마다 어절 단위로 채점합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.webmanifest` | 태블릿·휴대폰에 앱으로 설치하기 위한 정보 |
| `sw.js` | 오프라인에서도 열리게 해 주는 파일 |
| `icons/` | 앱 아이콘 |

## GitHub Pages에 올리기

1. GitHub에서 **New repository**를 눌러 새 저장소를 만듭니다. (예: `panrye-amgijang`, Public)
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 `icons` 폴더를 통째로 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/panrye-amgijang/` 주소로 열립니다.

## 태블릿에 앱으로 설치하기

- **갤럭시 탭(크롬):** 위 주소를 열고 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
- **아이패드(사파리):** 위 주소를 열고 공유 버튼 → **홈 화면에 추가**

설치하면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 없어도 열립니다.

## 알아 둘 점

- 판례와 입력 기록은 **그 기기의 브라우저에 저장**됩니다. 다른 기기로 옮길 때는 `판례리스트 관리 → 전체 JSON 복사`를 한 뒤, 다른 기기에서 `JSON 붙여넣어 가져오기`를 쓰세요. 가끔 JSON으로 백업해 두는 것을 권합니다.
- **사진에서 원문 추출**과 **암기 팁**은 Claude를 쓰는 기능이라 claude.ai에서 열었을 때만 작동합니다. GitHub Pages 버전에서는 판례원문을 직접 입력하거나, claude.ai 버전에서 만든 판례를 JSON으로 옮겨 오세요.
- 앱을 수정해 다시 올릴 때는 `sw.js` 맨 위의 `panrye-amgijang-v1` 숫자를 `v2`, `v3`…로 올려 주면 설치된 앱에도 새 버전이 반영됩니다.
